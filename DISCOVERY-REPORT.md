- **Framework:** Next.js 15 (App Router) + TypeScript + Tailwind CSS.
- **Components:** reusable design-system (buttons, cards, section shells, motion primitives).
- **Data/CMS:** Supabase (Postgres + Auth + Storage + RLS). Public read = published rows only; writes = admin-only.
- **Email:** Resend (contact + notifications), server-side, keys in env only.
- **Hosting:** Vercel (preview + prod), GitHub version control.
- **SEO:** metadata, OpenGraph, Twitter cards, JSON-LD (Person/Organization/Article/Breadcrumb), sitemap, robots.
- **Analytics:** Vercel Analytics (privacy-conscious) + optional GA4.
- **Security:** env-var secrets, input validation/sanitisation, rate-limited forms, secure headers, error boundaries, custom 404.
